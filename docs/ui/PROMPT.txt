请阅读 docs/ui/README.md 了解设计规范（色彩/字号/间距/等级颜色/五维评分颜色），
然后依次将 docs/ui/components/ 下的每个 .ux 文件转换到 src/Common/ 目录。

具体要求：

1. 每个组件在 src/Common/ 下创建同名 .ux 文件
2. <template> 和 <style> 从 docs 原样复制结构，不做任何视觉改动
3. 把模板里的 hardcode 示例值替换为动态绑定（{{props}}、for 循环等）
4. 自行添加 <script> 段，定义 props 和 computed
5. 颜色、字号、间距严格遵循 docs/ui/README.md 设计规范
6. 不要修改 docs/ 目录下的任何文件
7. 不要修改 src/ 下已有的页面文件（Camera/Upload/Result/Gallery 的 index.ux 和 app.ux）

转换完成后，用 import 方式把新组件集成到对应页面中：
- Camera 页：import CameraBox, SceneTag, GridControl, ShootButton, ParamPanel
- Result 页：import ScoreCircle, ScoreRadar, AdviceCard, IssueCard, BulletList, ParamPanel, ExpGainCard, LevelUpCard, BadgeUnlockCard
- Upload 页：import ModeSelector, ImagePicker
- Gallery 页：import PhotoCard
- Growth 页：import LevelBadge, BadgeTag, StatsPanel
